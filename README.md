# 🎬 FastClip - 智慧剪輯師 (v1.0)

**FastClip** 是一個極致簡約、智慧化的影片自動產生工具。最初是為了協助老師快速製作教學或活動紀錄影片而設計，但其強大且直覺的功能，也非常適合**個人旅遊紀錄、生活 VLog 或社群短影音**的快速產出。

只需一個資料夾，剩下的交給 **智慧剪輯師**。

---

## ✨ 核心亮點

- **🚀 零門檻啟動**：提供單一執行檔 (`.exe`)，無須安裝 Python、環境變數或 FFmpeg，雙擊即用。
- **📸 智慧 Ken Burns 特效**：照片自動隨機套用「放大」或「縮小」的平移縮放效果，讓靜態素材動起來。
- **⏱️ 智慧時長計算**：自動根據素材數量與您的設定計算最完美的影片長度，並醒目顯示預估時間。
- **🎵 多元背景音樂**：支援直接貼上 YouTube 網址或選擇本機 MP3 檔案，結尾自動漸弱處理。
- **🎞️ 專業級轉場**：所有剪輯點自動加入 0.5 秒的視覺淡入淡出，流暢不生硬。
- **📐 自動最佳化**：影片統一輸出為 1080p 解析度，素材自動縮放並補上黑邊。

---

## 🛠️ 如何開始使用？

### 【最推薦：直接使用執行檔】
1. 下載並進入 `dist` 資料夾。
2. 直接雙擊執行：👉 **FastClip_程式.exe**

### 【進階：分享與開發】
若要分享開發包給朋友，請包含以下檔案：
- `main_gui.py` (介面原始碼)
- `video_engine.py` (處理引擎)
- `setup.bat` (一鍵安裝環境)
- `run.bat` (一鍵啟動腳本)
- `README.md` (本說明文件)

---

## 📖 操作指南

1. **選取素材**：點擊瀏覽，選擇放有照片或影片的資料夾。
2. **時長設定**：
   - 設定每張照片停留秒數 (建議 3 秒)。
   - 設定影片素材的單段長度 (程式會自動截取精華)。
3. **背景音樂**：貼上 YouTube 網址或選擇檔案。
4. **預估長度**：查看介面上的「預估影片長度」文字，確認這就是您要的長度。
5. **立即產出**：點擊綠色按鈕，稍候片刻，成品會自動出現在**桌面**！
